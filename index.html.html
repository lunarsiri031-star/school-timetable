ระบบจัดตารางสอนโรงเรียนขยายโอกาส

จัดตารางเรียน–ตารางสอน • ตรวจสอบครูสอนชน • ปรับคาบด้วยตนเอง • ใช้งานแบบออฟไลน์

บันทึกและป้องกันข้อมูลสูญหาย

ข้อมูลในเบราว์เซอร์อาจไม่ตามไปเมื่อเปิดไฟล์โปรแกรมรุ่นใหม่หรือย้ายไฟล์ HTML • แนะนำให้ดาวน์โหลดไฟล์สำรอง JSON หลังจัดตารางทุกครั้ง

กำลังตรวจสอบข้อมูลที่บันทึกไว้...

การเชื่อมแฟ้มอัตโนมัติต้องอนุญาตการเข้าถึงไฟล์ และใช้งานได้เฉพาะเบราว์เซอร์ที่รองรับ หากไม่รองรับ ให้ใช้ปุ่มสีเขียวเพื่อดาวน์โหลด JSON แทน • ไฟล์ Excel/PDF สำหรับพิมพ์ไม่สามารถนำเข้ากลับเพื่อแก้ไขตารางได้

เชื่อมต่อข้อมูลออนไลน์ (ใช้ข้อมูลเดียวกันบนคอมพิวเตอร์และโทรศัพท์)

ตั้งค่าฐานข้อมูลออนไลน์ครั้งแรก และเข้าสู่ระบบด้วยบัญชีที่โรงเรียนอนุญาตให้ใช้ ข้อมูลจะซิงก์หลังจากเลือกโหลดข้อมูลออนไลน์หรืออัปโหลดข้อมูลจากเครื่องอย่างชัดเจน

ยังไม่ได้เชื่อมต่อฐานข้อมูลออนไลน์ โปรแกรมยังใช้ข้อมูลในเครื่องนี้ตามปกติ

เพื่อความปลอดภัย ต้องสร้างฐานข้อมูลและกำหนดผู้มีสิทธิ์ก่อนใช้งานจริง ระบบไม่เก็บรหัสผ่านไว้ในโปรแกรม และไม่ควรใส่ service_role/secret key ในหน้าเว็บ หากอินเทอร์เน็ตขัดข้อง โปรแกรมจะบันทึกในเครื่องและแจ้งว่ารอซิงก์

ข้อมูลสถานศึกษาและเวลาเรียน

วันเรียนเริ่มต้น: จันทร์–ศุกร์ การเปลี่ยนจำนวนคาบอาจทำให้คาบที่อยู่นอกช่วงใหม่ถูกลบเมื่อกดบันทึก

เริ่มต้นใช้งาน

กรอกข้อมูลครู ห้องเรียน และรายวิชา → กำหนดภาระสอนรายห้อง → ระบุเวลาที่ครูไม่สะดวก → กดจัดตารางอัตโนมัติ → ตรวจสอบผลและปรับตาราง → พิมพ์หรือส่งออกไฟล์

ข้อมูลบันทึกโดยอัตโนมัติในเบราว์เซอร์เครื่องนี้ ควรสำรอง JSON เป็นระยะ โดยเฉพาะก่อนล้างข้อมูลเบราว์เซอร์

นำเข้าข้อมูลจำนวนมากจาก Excel / CSV

ไม่จำเป็นต้องพิมพ์ทีละรายการ: คัดลอกตารางใน Excel (รวมบรรทัดหัวตาราง) แล้ววางช่องด้านล่าง หรือเลือกไฟล์ CSV ที่บันทึกจาก Excel โปรแกรมจะเพิ่มเฉพาะรายการใหม่โดยไม่ลบข้อมูลเดิม โดยยึดชื่อรายวิชาเป็นหลัก รหัสวิชาซ้ำกันได้ เช่น วิทยาศาสตร์/เทคโนโลยี สุขศึกษา/พละศึกษา และศิลปะ/ดนตรี-นาฏศิลป์

เลือกประเภทข้อมูล แล้ววางตารางจาก Excel หรือเลือกไฟล์ CSV

หัวตารางที่รองรับ: ห้องเรียน / รหัสวิชา / รายวิชา / ชื่อครู 1 / ชื่อครู 2 / ชื่อครู 3 / คาบต่อสัปดาห์ (ภาระสอน) หรือใช้แม่แบบที่โปรแกรมเตรียมไว้ หากนำเข้าภาระสอน โปรแกรมจะสร้างชื่อครู ห้องเรียน และชื่อรายวิชาที่ยังไม่มีโดยอัตโนมัติ โดยรหัสวิชาเดียวกันใช้กับชื่อวิชาต่างกันได้ ใช้ข้อมูลสำรอง JSON ก่อนนำเข้าข้อมูลจริงจำนวนมาก

ชั้นเรียน / ห้องเรียน

รายวิชา

นำเข้าภาระสอนจาก Excel / CSV โดยตรง

ใช้ไฟล์ 7 คอลัมน์: ห้องเรียน / รหัสวิชา / รายวิชา / ชื่อครู 1 / ชื่อครู 2 / ชื่อครู 3 / คาบต่อสัปดาห์ — เมื่อยืนยันแล้ว ระบบจะสร้างข้อมูลครู ห้องเรียน รายวิชา และภาระสอนในหน้านี้อัตโนมัติ ไม่ต้องเพิ่มซ้ำทีละวิชา (รองรับไฟล์ CSV UTF-8 และคอลัมน์ชื่อครู 4, 5, ... เพิ่มก่อนคอลัมน์คาบต่อสัปดาห์ได้)

ภาระสอนที่บันทึก: 0 รายการ

หมายเหตุ: ถ้าเคยนำเข้าข้อมูลแล้ว ระบบจะข้ามรายการตรงกันและแจ้งกรณีข้อมูลเดิมต่างกันโดยไม่เขียนทับอัตโนมัติ ก่อนเปลี่ยนข้อมูลจำนวนมากควรสำรอง JSON

กำหนดภาระสอนรายห้อง

1 รายการ = 1 รายวิชาใน 1 ห้อง โดยเลือกครูผู้สอนร่วมได้สูงสุด 3 คน ระบุจำนวนคาบต่อสัปดาห์ โปรแกรมจะจัดคาบให้ครบตามจำนวน

เวลาที่ครูไม่สะดวกสอน

ใช้กำหนดเวลาประชุม งานประจำ หรือคาบที่ไม่ต้องการให้จัดการสอน (เป็นข้อห้ามเด็ดขาด)

จัดตารางอัตโนมัติ

ระบบจะป้องกันครูสอนชนกัน ห้องเรียนชนกัน และหลีกเลี่ยงช่วงเวลาที่ครูไม่สะดวก รวมทั้งพยายามกระจายวิชาในแต่ละวัน การจัดใหม่จะทับตารางเดิม

ยังไม่ได้จัดตารางสอน

กำหนดสีประจำรายวิชา

เลือกสีหนึ่งครั้งต่อชื่อวิชา ระบบจะใช้สีเดียวกันทุกห้องและตารางสอนรายครู ตัวอย่าง: คณิตศาสตร์เป็นสีเขียวอ่อน • บันทึกสีลงข้อมูลสำรอง JSON และใช้สีในไฟล์ Excel / PDF ด้วย

คลิกเพื่อเลือกหรือเปลี่ยนสีแต่ละรายวิชา

PDF: เมื่อสั่งพิมพ์จาก Chrome/Edge ให้เลือก “พิมพ์พื้นหลัง / Background graphics” หากสีไม่ปรากฏ • Excel จะมีสีพื้นเซลล์ตามที่เลือก

ตารางเรียน

รูปแบบเอกสารทางการ: หัวเอกสารระบุโรงเรียน ภาคเรียน ปีการศึกษา และข้อมูลห้อง/ครู พร้อมสรุปจำนวนคาบและช่องลงชื่อผู้จัดตารางหรือครูผู้สอนและผู้ตรวจสอบ เช่นเดียวกับเอกสารสอนแทน • PDF และ Excel ใช้ฟอนต์ TH Sarabun New ได้ และพิมพ์ A4 แนวนอน

ตารางตามแม่แบบ ป.1: วันด้านซ้าย คาบและเวลาอยู่ด้านบน พักกลางวันระหว่างคาบ 4 และ 5 • สามารถส่งออก Excel เฉพาะห้อง/ครูที่เลือก หรือทุกห้อง/ครูได้โดยใช้ฟอนต์ตามที่ตั้งไว้ • หากต้องการให้ PDF แสดงครูประจำชั้น ให้กรอกในช่องด้านบนแล้วคลิกออกจากช่องเพื่อบันทึก

คลิกช่องคาบเรียนเพื่อเพิ่ม ย้าย หรือลบรายการได้ การแก้ไขด้วยตนเองจะตรวจสอบคาบชนก่อนบันทึก การล็อกคาบใช้ป้องกันการเปลี่ยนคาบนั้นขณะจัดตารางอัตโนมัติ

ระบบจัดสอนแทนรายวัน

เลือกวันที่และครูที่ไม่สามารถสอน ระบบจะดึงคาบจากตารางสอนหลักและแนะนำครูที่ว่างในคาบนั้นโดยอัตโนมัติ เลือกครูเองได้ และข้อมูลตารางสอนหลักจะไม่เปลี่ยน

กรุณาเลือกวันที่และครู

การส่งออกเอกสารรายวันจะรวบรวมรายการสอนแทนที่บันทึกไว้ของครูทุกคนในวันที่เลือก และใช้แบบอักษรชุดเดียวกับตารางสอนหลัก หากยังไม่ได้บันทึกการจัดสอนแทน จะไม่มีรายการให้ส่งออก

ตารางจัดสอนแทน

ในช่องครูผู้สอนแทน จะแสดงครูที่ว่างและไม่มีงานสอนแทนอื่นในเวลาเดียวกัน เรียงตามจำนวนคาบสอนแทนสะสม (น้อยไปมาก) ปุ่มบันทึกบันทึกได้ครั้งละคาบ

ตัวอย่างเอกสารสอนแทนรายวัน (แบบทางการ)

ตัวอย่างนี้รวมรายการสอนแทนที่บันทึกแล้วทั้งหมดในวันที่เลือก ไม่จำกัดเฉพาะครูที่กำลังแสดงด้านบน เอกสาร PDF และ Excel ใช้หัวตารางและชื่อฟอนต์เดียวกัน

ประวัติการจัดสอนแทนและภาระงานสะสม

รายการที่บันทึก

สถานะการจัดตาราง

สรุปจำนวนชั่วโมงสอนรายครู (ต่อสัปดาห์)

นับจากคาบเรียนปกติ โดย 1 คาบ = 1 ชั่วโมงสอนตามตารางเรียน (คาบละ 50 นาที) • ครูร่วมสอนนับให้แต่ละคนคนละ 1 ชั่วโมงต่อคาบ • ไม่รวมชั่วโมงสอนแทน • คอลัมน์ “จัดแล้ว” แสดงเฉพาะคาบที่อยู่ในตารางจริง

ตั้งค่าฟอนต์สำหรับ PDF และ Excel

ใช้ตัวเลือกเดียวกันกับเมนูจัดตารางสอน • ไฟล์ Excel จะบันทึกชื่อฟอนต์ลงในรูปแบบเซลล์ ส่วน PDF ใช้ฟอนต์จากเครื่องเมื่อสั่งพิมพ์ และอาจปรับสเกลให้พอดีหน้า A4 โปรดติดตั้ง TH Sarabun New บนคอมพิวเตอร์ก่อนพิมพ์หากต้องการให้แสดงฟอนต์ตรงตามที่เลือก

ส่งออกข้อมูล

ไฟล์ Excel จะแยกชีตตารางเรียนทุกห้อง ตารางสอนทุกครู และประวัติสอนแทน พร้อมสีรายวิชาที่กำหนดไว้ โดยจัดวันเป็นแถว คาบเป็นคอลัมน์ตามแม่แบบโรงเรียน ส่วน PDF ใช้คำสั่งพิมพ์แล้วเลือก Save as PDF ในเบราว์เซอร์; สำรอง JSON เพื่อแก้ไขข้อมูลในโปรแกรมภายหลัง
